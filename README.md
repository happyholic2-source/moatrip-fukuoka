# 모아트립 (MoaTrip) — 후쿠오카 Google Maps MVP v0.2

후쿠오카 Google Maps에서 장소를 검색하거나 지도에 등록하고, 여행방 코드를 공유하고, 선택한 장소들의 방문 순서를 추천하는 React Native 앱입니다.

## 포함 기능
- 후쿠오카 중심 Google Maps 지도 화면, 지도 길게 눌러 장소 추가
- Google Places API (New) 검색 결과에서 장소 추가 (키 설정 필요)
- 맛집/카페/관광/기타 핀 분류
- 로컬 장소 저장 (서버 설정 없이 동작)
- Supabase 설정 시 여행방 코드 기반 실시간 장소 공유
- 장소 선택 후 근사 최단 방문 순서 계산 (nearest-neighbor + 2-opt)
- 추천 방문 순서 및 지도 직선 연결 표시

## 실행
1. Node.js LTS와 Expo Go를 설치합니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. `npx expo start`를 실행하고 QR 코드를 Expo Go로 스캔합니다.
4. 지도 화면을 길게 눌러 장소를 등록합니다.

## 친구들과 공유하려면
1. Supabase 프로젝트를 생성합니다.
2. Authentication > Providers에서 Anonymous Sign-Ins를 활성화합니다.
3. SQL Editor에서 `supabase/schema.sql`을 실행합니다.
4. `.env.example`을 `.env`로 복사하고 Supabase URL과 publishable/anon key를 입력합니다. **service_role 키는 앱에 절대 넣지 마세요.**
5. `npx expo start --clear`로 재시작합니다.
6. 첫 사용자가 `새 코드`를 눌러 코드를 만들고 `참여`합니다. 친구들은 같은 코드를 입력하고 `참여`합니다.

## 주의: 현재는 프로토타입
- 동선 최적화는 **직선거리 근사치** 기준입니다. 실제 도로, 영업시간, 교통상황, 소요시간을 반영하지 않습니다. 지도 선도 도로 경로가 아니라 장소 간 직선 연결입니다.
- 지도에 길게 눌러 핀을 추가하므로 장소 검색, 실제 상호명 검증, 주소/영업시간 데이터는 아직 없습니다.
- 공유방은 별도 회원 권한 시스템 없이 코드로 구분하며, 제공된 RLS 정책은 **인증된 사용자가 모든 방을 읽고 수정할 수 있는 개발용 예시**입니다. 실제 서비스에 배포하면 안 됩니다. 정식 출시 전 `rooms`, `room_members` 테이블과 멤버십 기반 RLS, 초대 토큰 검증, 삭제 권한, 신고/차단, rate limit을 구현하세요.
- 실제 도로 동선은 네이버/카카오/Google Directions/Routes 등 적절한 API를 서버에서 호출해 구간별 이동시간 행렬을 만들고, 최적화 알고리즘으로 방문 순서를 계산한 뒤 도로 polyline을 렌더링해야 합니다. API 키는 서버에 보관하세요.
- 기기에서 위치 권한을 요청하지 않으며 초기 지도는 후쿠오카입니다. 사용자 위치 추적은 하지 않습니다.
- 온라인 상태, 지도 SDK 제공자의 서비스 정책, 플랫폼 설정에 따라 실제 기기에서 추가 설정이 필요할 수 있습니다.

## v0.3: 도보 전용 다일 일정
- 장소 탭에서 **몇 박 / 몇 일**을 입력합니다 (0박 1일~29박 30일; 일수=박수+1).
- 방문 장소를 체크하고 자동 일정 추천을 누르면 날짜별로 장소를 배분합니다.
- 동선 탭에서 `1일 차`, `2일 차` 등을 선택하면 지도 경로도 해당 날짜로 변경됩니다.
- 현재는 직선거리와 시속 4km로 이동시간을 근사합니다. **실제 Google Maps 도보 길찾기 결과가 아니며** 횡단보도/영업시간/출발시각/숙소 위치는 미반영입니다. 추후 서버에서 Google Routes API WALK 경로와 시간 행렬을 조회해 최적화해야 합니다.
- 하루 체류시간은 첫날/마지막날 6시간, 나머지 8시간, 최대 4개 장소로 가정합니다. 미배치 장소는 별도로 표시합니다.

## v0.4 여행 정보 입력
- 장소 탭에서 여행 시작일·종료일(YYYY-MM-DD), 첫날 도착 시각·마지막 날 출발 시각(HH:MM), 숙소를 입력합니다.
- 숙소는 Google Places 검색 결과에서 선택해야 좌표가 저장됩니다. 검색을 위해 Places API 키가 필요합니다.
- 설정은 현재 기기 AsyncStorage에 저장됩니다. **여행방 친구들에게 설정이 실시간 동기화되지는 않습니다.**
- 일정 추천은 숙소에서 출발해 숙소로 돌아오는 직선거리 기반 근사치이며, 첫날 도착 후 90분, 마지막 날 출발 전 120분을 예약합니다. 항공편/공항 이동, 실제 도보 길찾기, 영업시간은 아직 연동되지 않았습니다.
- API 키가 들어간 앱 배포 전에는 키 제한과 서버 프록시 등 보안 설계를 검토하세요.
